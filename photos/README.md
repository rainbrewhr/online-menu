# Menu photos

Put item photos in this folder, then type the file name in the **Photo** column of the Google Sheet.

- **Shape:** square works best. They show as small 64×64 thumbnails.
- **Size:** about 400×400 pixels, under 200 KB each, so the menu loads fast on mobile data.
- **File names:** lowercase with dashes, no spaces, e.g. `halo-halo.jpg`, `spanish-latte-float.jpg`.
- **File types:** `.jpg`, `.png` or `.webp`.

To upload on GitHub, open this folder and click **Add file → Upload files**, then **Commit changes**.
